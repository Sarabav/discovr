Workflows

What the agent runs end to end

AI Visibility Audit

Business Website Rule Checks AI Agent Dashboard
  1. Scrape the business's website for page copy, schema markup and crawler settings.
  2. Run the rule checks and score each category.
  3. Rank the findings by impact with AI and show the report in chat.

Fix My Site

AI Agent Fix Generator Rule Checks Dashboard
  1. The agent picks the highest-impact finding and explains why.
  2. Generates a fix grounded in the business's real content.
  3. Verifies its own output and loops to the next finding until everything is resolved or needs the owner.

Weekly Re-Check

Business Website Rule Checks AI Agent Dashboard
  1. Re-scrape and re-score the site on a schedule.
  2. Compare against the previous audit stored in memory.
  3. Report what changed and alert the owner if the score moved. Runs as a cron job.
